# emotes (native mod, by giruka)

Link's emotes and a ragdoll toggle: docs/emotes.md has the list, the keys and how to make your own.

- `emotes.c`: the whole mod (Link's update wrapper, the play/stop state machine, keys 5-0, the `emote` console
  command, the Mods page buttons, developer `emotedbg`, the physics ragdoll behind `emotedbg rdphys on`).
- `emote_list.h`: generated by `python tools/emote_build.py header` from tools/emotes/*.json (with the generated block
  at the end of `mod.toml`). Tests check both are in sync.
- `selftest/emotes_selftest.c`: includes emotes.c and fakes the game calls with a made-up Link and AI tree
  (tests/test_emote_build.py builds and runs it with Savage Wind's zig).
